# Personal Dev in 3D

Portfolio V2 is a React, Vite, Tailwind, and React Three Fiber portfolio focused on a premium interactive experience with a lighter rendering path, shared interaction state, and device-aware motion.

## Scripts

```bash
npm run dev
npm run build
npm run lint
```

## Current V2 Direction

- Procedural Three.js hero object instead of heavy model assets.
- Shared experience provider for pointer smoothing, reduced motion, and device tier.
- Reusable magnetic and tilt primitives for premium interactions.
- Reduced particle usage and removed dead V1 canvas files from the active app path.
